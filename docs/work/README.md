# Project Work Queue

[`TODO.md`](TODO.md) is the repository-local source of unfinished implementation, review, and standards work. Keep work here until it is resolved or moved to a clearly identified external tracker. Do not use the queue as a substitute for current architecture docs or ADRs.

When a session finds work it cannot complete, add an item with its goal, scope, acceptance criteria, verification, affected areas, dependencies, risks, and next action.
